# Marks

One mark per coding agent Carbon recognises, named after the harness's id in `src/harness.rs`. Both the desktop
app and the page draw them on a dark tile, so single-colour marks are light. A harness without a file here is
shown by its first letter.

Where they come from:

- `oh-my-pi.svg` is the icon in the [oh-my-pi](https://github.com/can1357/oh-my-pi) repository (MIT), centred in a
  square.
- Every other file is from the [@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons) set (MIT),
  version 1.102.0, with single-colour marks set to a light grey. Codex uses OpenAI's mark.

`tech/` holds one mark per tool in `src/stack.rs`, named after its id: the drawings are from
[Simple Icons](https://github.com/simple-icons/simple-icons) (CC0), version 16.38.0, in each brand's own colour, or
in light grey where that colour is too dark to show on a dark tile.

Each mark is its owner's trademark. Carbon uses them only to say which tool started or runs something, and is not
affiliated with or endorsed by any of them.
